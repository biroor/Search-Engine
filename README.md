🔍 Biroor Search Engine & Ecosystem
Biroor Search is a privacy-focused, customizable search hub and productivity dashboard. Unlike static search engines, Biroor empowers users to shape their own web experience through a modular add-on system and community-driven content indexing.

✨ Key Features
Customizable Search Interface: A clean, modern UI that serves as a launchpad for your digital life, featuring quick access to favorites and powerful search tools.

Biroor Add-on Store (Eklenti Mağazası): * Web Guard: An integrated security layer that scans URLs for risks (phishing, gambling, etc.) in real-time.

Theme Engine: Fully customizable aesthetics, including official themes like "Emerald."

AI Integration: Tools like "Bazlamaç AI" that bring collective intelligence directly into your search results.

Community-Driven Indexing: A unique "Add a Website" feature allows users to contribute to the engine's database. Entries are processed as JSON and stored in a lightweight veri.txt format, allowing for a fast, decentralized search experience.

Integrated Productivity Tools: Built-in features like a calculator, site manager, and brand indexer help keep everything you need in one tab.

🛠 Technical Highlights
Modular Architecture: Designed to load external JavaScript-based extensions dynamically.

Data Handling: Uses a streamlined JSON-based entry system for fast retrieval and easy data management.

Security Focused: Features built-in content filtering and domain analysis to protect users from malicious web content.

🎯 The Vision
Biroor Search aims to de-clutter the internet. By combining a search engine with a plugin store, it transitions from a simple query tool into a personalized web workstation. It’s built for users who want control over what they see and how they interact with the web.
